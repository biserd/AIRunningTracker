scores, HRV units and retention before producing normalized records. The ops
script generates a private SQL file but does not execute it. Every insert checks
the target owner, existing health consent and HEALTH_EXPORT permission, and
skips any already stored reading of the same kind/date. It does not change
health consent, OAuth tokens, Garmin push timestamps or activity records.

Imported records have source=garmin_connect_history and an import timestamp.
Dashboard cards and sleep detail label their provenance. Future live Garmin
summaries supersede imported copies, including corrected shorter sleep windows.
Missing nights stay blank. Privacy text explains separately requested history
imports; automatic Starter sync still has no backfill feature. Retention,
export, stop/delete and no-AI/no-messaging controls apply as before.
